Raised by [`C-0090`](../claims/C-0090-buildable-raster-width.md)'s *Still open* item 2,
which names the question and declines to answer it:

> **Which end-of-row convention is right.**
> It is a question about whether a crossover can be drawn at the last base pair of a duplex,
> and it is worth the whole verdict (0.0621 against 0.1684).

**Leaf**: `A8.2` (the plan and lattice model the anchoring array is written on), with `A1.2`.

**Reserved IDs**: claim `C-0095`, challenge `CH-0111`.

## Formulate

### The question

At `C-0086`'s buildable seamless raster width the tile is **exactly seven column pitches** —
`38.08 = 7 × 5.44` nm, where §3's nominal 40.0 nm is 7.35 —
so at the phases `b ≡ 8 (mod 16)`, i.e. `C-0063`'s own centro-symmetric pair 8 and 24,
a crossover column lands **on the row end**.

`CrossoverLayout.EDGE_MARGIN = 0.05 nm` deletes it.
That constant is documented as a **numerical guard** —
*"a column exactly on the edge would seed a zero-length beam element"* —
and it is inert at 40.0 nm, where no base-pair phase brings a column within 0.28 nm of the edge.
At 38.08 nm it stops being inert and starts making a **physical assertion**,
and the assertion is worth the whole flatness verdict.

### Locked units, geometry and sign conventions

- Lengths **nm**, forces **pN**, stiffness **pN/nm**, pressure **pN/nm²** (= 1 MPa exactly),
  `k_BT = 4.141947 pN·nm` at **T = 300 K**, aqueous **2 mM MgCl₂**.
- `x` runs **along** the helices, `y` **across** them, `z` normal and positive **upward**; `w` positive **downward**.
- **A row** is one duplex; **a plane** is `C-0055`'s 8 bp crossover plane;
  **a column** is the sheet's own 16 bp column lattice, of which the planes are every other member;
  **an interface** is the boundary between two adjacent duplexes, indexed `b = 0 … D−2`.
- **The row end** is `x = ±edgeX/2`, the last base pair of the duplex.
  A crossover *at* the row end is one whose base-pair position is that terminal base pair.
- **A raster turn** is the scaffold crossover at which a boustrophedon passes from one row to the next.
- Row length **112 bp = 38.08 nm** (`C-0086`), rise **0.34 nm**, column pitch **16 bp**,
  per-interface crossover spacing **32 bp**, **15** duplexes at the SAXS 2.69 nm.

## Plan

### The cheap bound runs first, and it is two counts and a reading

1. **The covalent count, before any search.**
   `CLAUDE.md` records that a duplex **END** has exactly two strand termini.
   A crossover consumes **one** strand continuation.
   The 33.74°/bp azimuthal quantum then fixes *which* neighbour a given base pair's crossover can reach,
   so a terminal base pair offers at most **one** crossover, to one neighbour.
   Ask what a boustrophedon **demands** at a row end and compare: if the demand exceeds one, the geometry refuses.
2. **The parity congruence.**
   A boustrophedon's raster turns at one edge join interfaces of **one parity** and at the other edge the **complementary** parity.
   The column lattice assigns each column a parity and interface `b` carries the columns whose parity matches `b mod 2` (`CrossoverLayout`).
   So the row-end columns can be the raster turns **only if** they carry opposite parity,
   which happens **iff** the row is an *odd* number of column pitches.
   `C-0086`'s odd-half-turn rule says it always is.
   If that fails, the identification of the row-end column with the scaffold turn is wrong and the whole argument collapses.
3. **The reading.**
   Rothemund 2006 and its Supplementary Notes are **already in this repository**
   (`gpd/data/T-151-sources/`, fetched and manifested by `T-151`), so the primary source costs a `grep`.
   Search it for what happens at a vertical edge, and for the dimensions of the structures he actually built:
   if a built rectangle's row length is a whole number of column pitches, the question is settled by a folded structure and not by an argument.

**Only if the cheap bound is inconclusive** does this task spend a literature sweep.
Cost justification: the three steps above are minutes; a full EuropePMC sweep with the 8 s spacing
`CLAUDE.md` mandates is an hour, and a delegated one is what fabricated two of four sub-reports in this project.

### Then, and only then

4. **Recorded EuropePMC searches** for an explicit prohibition, saved with their raw JSON into `gpd/data/T-161-sources/`.
   A negative existence result is only falsifiable if the queries are recorded.
5. **The design language**: the caDNAno paper's own statement of what the software permits
   (`gpd/data/T-151-sources/PMC2731887-fullTextXML.xml`, already local), read directly.
6. **The verdict**, computed: `C-0090`'s two readings pulled out of its result file and the recommended one named.

### What would falsify this approach

If the answer turned out to depend on a *quantitative* strain calculation at the edge crossover —
a base-pair-level or all-atom question — then a reading task is the wrong instrument
and the honest output is a task for oxDNA or an NDI specification question, not a verdict.
