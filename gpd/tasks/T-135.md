## Formulate

### The question, as a predicate

**Acceptance.** A stated recommendation with

1. its **premises**, each flagged `derived` / `cited` / `undemonstrated`, counted;
2. its **margins**, and an explicit count of the quantities on which it has **none**;
3. the **specification questions** it is conditional on, each checked for whether it still binds *this* element;
4. its **failure routes, counted** — each being a single standing result which, reversed, removes the recommendation;
5. a **verdict against §6's acceptance predicates in NDI's own terms**;

— **or** the plain statement that the programme cannot yet recommend an output element, with what would decide it.

### Units and conventions, restated rather than inherited

- Lengths **nm**, forces **pN**, stiffness **pN/nm**, rotational stiffness **pN·nm/rad**;
  `k_BT = 4.141947 pN·nm` at **300 K** in aqueous **MgCl₂** at the stated concentration.
- `x` runs **along** the host sheet's helices, `y` **across** them, `z` **normal and positive upward**, away from the grafted layer.
- **A margin is a ratio and it carries a sense.** Against a **ceiling** it is `limit/value`; against a **floor** it is `value/limit`.
  Both are ≥ 1 when the requirement clears, and both are dimensionless.
  A margin is classified `VIOLATED` below 1, `NONE` below 1.05, `THIN` below 1.5, `COMFORTABLE` above.
  The 1.05 threshold is **declared here and is a convention**, chosen so that a margin smaller than the coarsest
  quantum this programme can build — one base-pair rise on an 8 nm member, 4.2 % — counts as none.
- **A premise is what the recommendation would lose if the statement were withdrawn**, and it is flagged by
  *how it was obtained*, never by how confident anyone is: `DERIVED` here or in a named claim, `CITED_MEASURED`,
  `CITED_MODEL_INPUT`, `CITED_FITTED`, `SPECIFICATION` (a §3 row or an unanswered question to NDI), or
  **`UNDEMONSTRATED`** — a motif this programme constructed and the literature does not contain.
- **A failure route is a single standing result**, reversed. Routes are classified by **effect**
  (`REMOVES_THE_ELEMENT` / `REMOVES_A_PREMISE` / `CHANGES_UNIQUENESS`) and by **what would decide them**
  (`CALCULATION` / `MEASUREMENT` / `SPECIFICATION` / `EXPERIMENT`), and separately by whether the reversal is
  **already inside a published bracket** — i.e. not hypothetical at all.
- **The recommendation is written at §3's ACCEPTABLE clause**, 100 pN over 3 nm, because `C-0050` establishes
  the desired 10 nm clause is unreachable on §3's own stack. Every number below is read there.

## Plan

### The cheap bound, which runs first

**The decision is decidable iff the tie-break between the elements that survive every standing clause is unanimous
on axes that are already established, and needs no new calculation.**

`C-0069` funnels an 11-row element catalogue to **3 that place 34 instances at one level** and **2 that survive
every clause**. Two survivors is not a recommendation. So the cheap bound is a *ranking*, on three axes each of
which is a **count** owned by a standing claim and not a new result:

1. the number of **undemonstrated motifs** the element requires (`C-0055`, `C-0028`);
2. the number of `C-0017`'s six 2 mM stability floors the assembled array **clears** (`C-0069`);
3. the number of **compression members** the element contains (`C-0023`, `C-0028`).

**Declared falsifier.** *If the three axes disagree — if any survivor wins one axis and loses another — the
programme cannot recommend without new work, and this task's answer is the negative one.* That is a real
possibility and it is what makes the bound worth running before the ledgers.

Cost: three integer comparisons against a result file already on disk. Everything expensive below is spent on
*re-deriving* what the recommendation carries, not on finding it.

### The expensive half, and why it is spent

Three of the five gates are discharged only by re-running the owning libraries: the arm's length and its two
end-restraint ceilings are bisections on `C-0039`'s exact elastica, and quoting them from `C-0069`'s result file
would make this synthesis a transcription. §7 asks that inherited numbers be re-derived. So every headline in
the recommendation is recomputed from the library that owns it and the departure quoted — the same discipline
`window.SecondResynthesisKt` established for the design window.

### What would falsify this approach

- **The tie-break axes disagreeing** (declared above) — then the answer is *"cannot yet recommend"*.
- **A reproduction failing.** If a number the recommendation rests on does not come back out of its own library,
  the synthesis is transcribing rather than deriving and the claim must be withdrawn.
- **The premise ledger containing no `UNDEMONSTRATED` entry.** The programme's own literature findings
  (`C-0055`, `C-0028`) say it must; a ledger that came back clean would mean the ledger was built from the
  design's advocates rather than from its provenance.
- **The failure-route count coming out at zero.** A recommendation with no route out is a recommendation that
  was not audited.

### What this task does NOT do

- It does **not** compute the pull-in fold for the recommended element. `C-0032` computed one for `C-0030`'s
  flexure, a **different** element, and `CLAUDE.md`'s own rule forbids transferring a fold margin between load
  lines. It is named as open item 1 and priced, not answered.
- It does **not** supply a tolerance model. That is `T-134`, running concurrently, and the two 0.0256 nm
  quantities are handed to it with the finding of which of them actually binds.
- It does **not** re-open any upstream verdict. Where this synthesis disagrees with an upstream reading it
  raises a challenge.

## Verify

| gate | what is checked |
|---|---|
| **1 — dimensional** | a margin is a **ratio** and is invariant under a common rescaling of value and limit; the plan margin is a **length** and scales linearly with the lattice; unphysical arguments throw |
| **2 — limiting cases** | a one-survivor set is unanimous trivially; a set tied on every axis reports **no winner**; a strictly dominated candidate never wins; a margin exactly at its limit is `NONE`, not `VIOLATED` |
| **3 — symmetry and conservation** | the funnel counts **conserve** (survivors + rejected = catalogue); every route carries exactly one effect and one decider; the premise statuses **partition** the ledger; the classification is monotone in the margin |
| **4 — numerical convergence** | the elastica arm is RK4-step independent (200 → 800); the two restraint ceilings are bisection-resolution independent; the study is deterministic on a re-run |
| **5 — literature and upstream** | every number the recommendation writes is reproduced from the claim that owns it, with the departure quoted |
