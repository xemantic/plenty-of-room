## Formulate

`C-0104` established the **threshold** and left the **value** open:

> *"The threshold sits between the 16 bp rung and the 32 bp rung. Which of the two is the physical one is exactly what Rothemund says is unknown — and it is the whole of the remaining exposure."*

`C-0099` recommended **against** an oxDNA edge-crossover run, on the ground that it would refine a
*stiffness* worth 2.85 % of an interval the verdict does not cross. `C-0104` changed the case: a
prestrain is a **load**, `T-5b`'s 0.10 sits at **15.4497275°** of uniform row-end prestrain
(`dishingPerRadian = 0.140379322` at `C-0090`'s placement), and the lattice's own register ladder
reaches **17.143°**. The question this task asks is whether anything — a bound, a source or a
derivation — puts the physical value on one side of 15.45°.

### Units and conventions, restated rather than inherited

- Angles **rad** (degrees only where a source quotes them), rotational stiffness **pN·nm/rad**,
  torsional rigidity **pN·nm²**, couples **pN·nm**, lengths **nm**, forces **pN**;
  `k_BT = 4.141947 pN·nm` at 300 K, aqueous 2 mM MgCl₂.
- `x` along the helices, `y` across them, `z` normal and positive **upward**; `w` positive **downward**.
- A **prestrain** `θ₀` is `C-0104`'s: the relative roll a crossover is **built at**, so its hinge
  stores `½k_θ(Δφ − θ₀)²`. Positive `θ₀` rolls the upper duplex positively relative to the lower.
- `u(x)` is the **azimuthal register error** of a duplex at position `x`: the phase by which its own
  backbone lags the phase the crossover lattice was laid out at. `u = 0` is a duplex wound to the
  **design** twist; `u' = Δω` is a duplex wound to its **natural** twist.
- The **row centre** is `x = 0`; the row ends are `x = ±edgeX/2` at `edgeX = 38.08 nm`.

### Acceptance predicate

- **`P1`** every accessible **ceiling** on a row-end crossover's prestrain is stated, derived here,

- **`P4`** `C-0099`'s recommendation against an oxDNA edge-crossover run is either upheld or
  reversed, and if reversed the run is **costed** against this box.

## Plan

### The cheap bounds, and why they run first

Four ceilings, none of which costs a solve. If **any** of them lands below 15.45° the task closes
there and `C-0099`'s recommendation stands.

1. **Rupture.** A prestrained crossover is a strained covalent junction. `k_θ = 2 k_bond a²` with
   `a ≤ r_P = 1.0 nm` (`C-0029`'s two termini on a chord), so the per-bond force is
   `F = k_θ θ₀/(2a)` and the allowable inverts to `θ₀ ≤ 2 a F/k_θ`. Evaluated at the unzip
   (10–15 pN) and shear (48–65 pN) allowables `CLAUDE.md` carries.
2. **The register quantum.** The design variable at an edge is a **domain length in base pairs**
   and Rothemund minimises the strain over it by hand, so the residual after optimal rounding is at
   most half a base-pair step. This is `C-0104`'s *half the azimuthal quantum* rung, re-derived.
3. **Rothemund's own remedy**, read as a scale: *"one or two scaffold bases could be left unpaired
   … that should relax the crossover"*. One unpaired base is one base pair of torsional slack.
4. **The twist boundary layer — the one this task adds.** `C-0104`'s ladder is a **per-crossover
   offset**: the register error of one 8/16/32 bp domain. But the error of every domain has the
   **same sign** (16 bp represents 1.5 turns at 33.75°/bp against B-DNA's 34.29°/bp), so it
   *accumulates* along a duplex, and the duplex's own torsion is what limits the accumulation. The
   smeared energy of one duplex is

   &nbsp;&nbsp;&nbsp;&nbsp;`E = ∫ [½C(u′ − Δω)² + ½(k_θ/p)u²] dx`,

   whose Euler-Lagrange equation is `u″ = u/λ²` with `λ = √(C p/k_θ)` and whose **natural** boundary
   condition at a free duplex end is `u′ = Δω`. So

   &nbsp;&nbsp;&nbsp;&nbsp;`u(±L/2) = ± Δω λ tanh(L/2λ)`,

   which is the residual a **row-end** crossover carries, is **odd about the row centre**, and has
   the two limits `Δω L/2` (rigid duplex) and `0` (rigid hinges). It is a closed form in constants
   this project already carries.

### The distribution, which is a symmetry question and not a measurement

`u` is odd in `x`; Rothemund's **glide symmetry** flips the crossover type column to column, and a
column of parity `p` serves the interfaces of parity `p` (`C-0015`), so the induced fold carries a
factor `(−1)^b` in the interface index. A boustrophedon's raster turns alternate ends, so the
row-end crossover of interface `b` sits at `x = (−1)^b L/2`. The two signs **compose**, and which of
`C-0104`'s three distributions that selects is a two-line derivation with no free parameter.

### Justification against cost

The alternative is the oxDNA or all-atom edge crossover itself. Four ceilings and one closed form
cost an afternoon and decide whether that run is worth its days. If any ceiling lands below 15.45°
the run is refused on arithmetic; if the derived value lands above it, the run is warranted and the
same arithmetic says what it must resolve to be worth running.

### What would falsify this approach

| # | falsifier |
|---|---|
| **F1** | the twist-boundary-layer model fails its own limits — `k_θ → 0` must give the free-duplex `Δω L/2` and `k_θ → ∞` must give 0 |
| **F2** | *(the declared one)* **every** ceiling lands below 15.4497275°, so the question closes on the cheap bound and `C-0099`'s recommendation stands |
| **F3** | the derived field does not reproduce `C-0104`'s published `dishingPerRadian = 0.140379322` and `0.0621469105` when run through the same pipeline |
| **F4** | a source **quantifies** the residual angle, in which case this is a value and not a bound |
| **F5** | the sign composition does not select one of `C-0104`'s three distributions |
| **F6** | the standing uniform-load falsifier: a uniform load on a uniform foundation dishes more than `1e-6` of the free stroke, read on `OrigamiGrillage.withoutPrestrain` (`CH-0120`) |
