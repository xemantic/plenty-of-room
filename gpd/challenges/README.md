# Challenges

A result that contradicts a standing claim is filed here as a challenge, with methodological grounds.
Claims in `../claims/` are never silently overwritten — §5 of the problem definition is explicit about this,
and it is the difference between a record and a rolling opinion.

A challenge names: the claim it contradicts, the result that contradicts it, the methodological grounds
(not merely a different number), and the resolution — which may be that the challenger is wrong.
