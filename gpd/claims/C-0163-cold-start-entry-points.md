## The claim, in one line

The table that tells a cold session **how to run anything** had 99 rows for 123 studies that write
a committed result file; three of the twenty-four missing were `PlanToleranceStudy`,
`DuplexPairSeparationStudy` and `BeyondMeanFieldGapStudy` — the emitters of three of `P-27`'s eight
stale files — so **the blocking task of this iteration could not be started from this repository's
own documentation.** The table is now complete, every added cell was derived by a tool from the
study's source rather than typed by a person, and the tool is a gate in `tools/verify.sh`.

## 2. Why this is a tool and not an edit

Twenty-four rows is twenty minutes of typing, and typing them is how the third defect kind gets
in. Each row's `Emits` cell has to be read out of a Kotlin source, and **neither end of the source
is safe**:

- **ten** of the twenty-four read `gpd/results/T-3b-tile-edge-load-profile.json` *before* writing
  their own output, so the **first** results path in the file is an input;
- **two** — `stability/LargeRotationArmBranchStudy.kt` (`T-157`) and
  `coupling/OutputCouplingStudy.kt` (`T-16`) — read an upstream result file **after** their own
  `writeText`, so the **last** results path in the file is an input too.

The first draft of the checker used the last-match rule. It reported those two as `EMITS-MISMATCH`
against rows that are **correct** — a false positive in the exact shape of a real finding, on a
gate whose entire value is being believed. `CLAUDE.md` already carries the rule it broke: *a drift
checker's false positives cost more than its true ones*, because the rate at which a gate is wrong
is the rate at which it gets switched off.

The reading that is about **writing** is to follow the binding — `val output = File("…")` — to its
`.writeText`. That is what ships, and both wrong rules are named tests:

- *"the written path is the one that is written, not the first one read"*
- *"nor the last one read, when a study reads an upstream file after writing its own"*

**A second false positive came from the checker's own regular expression**, which is the failure
`CLAUDE.md` records as *a checker's blind spot is invisible in exactly the cases it misses*: the
row pattern required the task cell to hold a single backticked tag, and **three** rows carry two
(`` `T-75` / `T-78` ``). Those three read as `MISSING-ROW`. Held open now by
*"a row whose task cell carries two tags still parses"*.

## 3. What the gate refuses, in both directions

Fourteen self-tests, and the three defect kinds are each held open by at least one:

| kind | what it means | named test |
|---|---|---|
| `MISSING-ROW` | a study writes a result file and no row runs it | *"a study with no row is MISSING-ROW"* |
| `UNKNOWN-STUDY` | a row names a study no source declares | *"a row naming a study that does not exist is UNKNOWN-STUDY"* |
| `EMITS-MISMATCH` | a row's `Emits` cell names a file the study does not write | *"a row naming the study's INPUT file is EMITS-MISMATCH"* |

And two tests hold the **exemptions** open, which is the direction a predicate is usually never
tested in: *"a study that emits nothing is NOT owed a row"* and *"a study listed twice is not a
defect"* — the second because a study legitimately appears under two tasks that both re-ran it.

## 4. The other two parts of `P-28`

**The orientation.** `## Start here — the state after iteration 26` was the heading over the
reading order a cold session is told to trust, and the queue was at iteration **38**. Its five
items had been annotated with supersessions in place, so the note was **correct and mis-titled** —
which is worse than stale, because the reader who checks the date discards five correct
annotations. Retitled, with the retitling recorded in the note rather than silently applied.

**The shadow corpus.** `./--check/` was **144 result JSONs from 2026-08-19**, untracked, differing

beside the real one. Nothing read it, and `CLAUDE.md` records what happens when a census reads a
directory nobody meant it to. Removed.

## 5. Validity range

- This is a claim about **documentation and a checker**, not about the device. It carries no
  physics, no units and no operating state.
- The gate checks that a row **exists** and that its `Emits` cell is **right**. It does **not**
  check that the command runs, that the run time in the cell is current, or that the task tag is
  the task the study now serves. Those are three further predicates and none of them is cheap;
  the run times of the twenty-four added rows are deliberately **absent** rather than invented.
- `123 of 124` is a property of this tree at this ref. A study whose output is stdout only, or
  which writes through something other than a `File` binding, is exempt **by construction and
  silently** — the checker cannot distinguish *"emits nothing"* from *"emits by a route I cannot
  read"*, and an exemption is not reported as a defect. **That is where this checker's one false
  negative was found**, and it was found by reading the exemption list rather than the defect
  list: `electrostatics/PlanarCouplingWallStudy.kt` takes an output override from the command line
  and puts its committed path on an `else` branch three lines below `File(`, so a single-line
  binding pattern read it as emitting nothing. It has a row already, so nothing was wrong in
  `TASKS.md` — the gate simply could not have noticed if there had been. Repaired by walking the
  argument list to its matching parenthesis, held open by a named test, and **the exemption list is
  now one study long**, which is short enough to read.

- **The scope is `gpd/results/`, and that was tested within the hour.** `T-266` ([`C-0160`](C-0160-scadnano-writer.md))
  opened a second committed-artifact directory, `gpd/designs/`, while this claim was being written.
  Widening the gate to cover it was **tried and reverted**, on the emitter's own argument: a design's
  staleness is caught by `CommittedDesignsTest`, which rebuilds the file and compares it **byte for
  byte**, and that is strictly stronger than a row saying how to run something. A row answers *how
  do I re-run this*; a rebuild-and-compare test answers *is this file what the code produces*.
  Where the second exists the first is documentation, and `gpd/designs/README.md` carries it.
  The second reason is the one `CLAUDE.md` already records and it is the harder one: that emitter
  assembles its path from a **directory constant and a name**, which is invisible to a search for
  either half — the shape that made `C-0073`'s reader audit miss two thirds of its own graph. **A
  checker that silently cannot see a whole emission style must not claim that style as its scope**,
  so the limitation is written into the tool's header rather than left as a clean run.
