## 12. Validity range, and what this does NOT establish

- **The classification is a judgement**, recorded per row and per occurrence with its reason, so a
  reader can disagree with any single entry without discarding the sweep.
- **It is a SNAPSHOT** at commit `a414045`, and the denominators MOVED while it ran. Two sibling agents
  were writing: the open-row count read 57 as found, 59 after the two mis-closed rows were repaired
  (§10) and 58 once a sibling closed `T-232`; the corpus count read 240 in 21 files before this claim
  existed and 265 in 23 once this claim and a sibling's `C-0142` entered it. **The reproducible
  statement is the CLASSIFICATION and the rules that produce it, not the denominator** — both are
  regenerated by `tools/T-234-emit-classification.py`, and a file added afterwards surfaces as
  `unclassified`, which is the gate working rather than failing.
- **The five premise families are a choice.** A statement that moved for a reason outside them is not
  found here, and the tool's context requirements — `112 bp` needs a honeycomb context,
  *"perpendicular"* needs an azimuth context — **trade recall for a false-positive rate low enough that
  the gate can be believed**. `CLAUDE.md`: *a drift checker's false positives cost more than its true ones.*
- **The pointer test is FORWARD only**, so a passage whose annotation *precedes* the number reads as
  unpointed. Three occurrences of `ANSWERS.md` row (g) are in that position; they are deliverable-scoped
  and reported as `T-233` debt regardless.
- **This task edits neither deliverable**, and it re-derives no physics. It does not re-grade
  `C-0118`'s coupled cells (`T-232`) and does not settle the scaffold (`CH-0180` names what would).
- **The census tool inherited `check-corpus-links.py`'s own blind spot and it was repaired here.**
  `git ls-files` does not list an uncommitted file, so on its first run the census could not see the
  claim that was about to raise it — 240 occurrences in 21 files against a true 261 in 22 at that moment. It now
  adds `--others --exclude-standard`, with a self-test that names this claim's own path. **The run an
  agent makes on its own work is the blind one**, and that is the third instrument in this repository
  found with that defect.
- **REPRICED is not KILLED and not ANSWERED.** Every repriced row is live exactly as written.
